# ขอบเขตระบบร้านค้า สมาชิก และ CRM

สถานะ: เริ่มทำ Preview เท่านั้น ยังไม่รองรับการสั่งซื้อหรือเก็บเงินจริง

## ระบบที่ต้องพัฒนาและเชื่อมต่อก่อนใช้งานจริง

1. แค็ตตาล็อกแยก SKU/ขนาด ราคาต่อหน่วย ภาษี จำนวนคงเหลือ รูปสินค้า ความเข้ากันได้ และชุดสินค้า พร้อมหลังบ้านจัดการและประวัติการเปลี่ยนแปลง
2. ตะกร้าจริงและคำสั่งซื้อ: คำนวณราคาที่เซิร์ฟเวอร์ ตรวจสต็อก จองสินค้า สถานะออเดอร์ ตรวจสอบรายการติดตั้งและนัดหมาย ยกเลิก/คืนเงิน และป้องกันการทำรายการซ้ำ
3. เชื่อม payment gateway ในโหมด sandbox ก่อน ต้องตรวจสอบ webhook/lifecycle ให้ถูกต้อง ไม่เก็บข้อมูลบัตรเอง และไม่ระบุว่าชำระสำเร็จจากการกลับมาหน้าเว็บอย่างเดียว
4. สมาชิก: LINE Login/LIFF ร่วมกับ LINE OA ตามสิทธิ์ที่มี ตรวจสอบ state และ token ฝั่งเซิร์ฟเวอร์ และแยกการยินยอมรับข้อความกับการสมัครสมาชิก
5. CRM: อัตราแต้มและวันหมดอายุตั้งค่าได้ แยกบัญชีรายการแต้มเพิ่ม/หัก/หมดอายุ/คืนเงิน มีกติกาการแลกของรางวัลและตรวจสอบการใช้สิทธิ์ซ้ำ QR สำหรับใช้ที่หน้าร้านต้องปลอดภัยและตรวจสอบบนเซิร์ฟเวอร์ ไม่ไว้ใจข้อมูลจากภาพ QR เพียงอย่างเดียว
6. Shopee/TikTok: ตรวจสอบสิทธิ์และการอนุมัติ API แยกแต่ละแพลตฟอร์ม จับคู่สินค้า คำสั่งซื้อ สถานะและสต็อกแบบ idempotent พร้อม reconciliation แก้กรณีซิงก์ล้มเหลว และกำหนดว่าช่องทางใดเป็นแหล่งข้อมูลหลัก
7. โปรโมชั่น: จัดการช่วงเวลา เงื่อนไข สินค้า สาขา และการซ้อนส่วนลดได้ กำหนดผู้อนุมัติรายเดือน ตรวจสอบวันหมดอายุ และห้ามเผยแพร่เงื่อนไขที่ยังไม่ยืนยัน
8. UAT: MariaDB และไฟล์แยกจากระบบจริง ใช้ข้อมูลทดสอบ ป้องกันการเข้าถึง มี HTTPS ตรวจสอบสิทธิ์ บันทึก audit และทดสอบ workflow ก่อนรับเงินจริง

## ข้อมูลที่ยังต้องขอ

- แค็ตตาล็อกสินค้าพร้อม SKU ขนาด ภาพ ราคา และสต็อกที่สาขาอนุมัติ และเงื่อนไขค่าบริการติดตั้ง
- ผู้ให้บริการชำระเงินที่บริษัทเลือก ข้อกำหนดการคืนเงิน และช่องทางสมัคร sandbox โดยไม่ส่ง secrets ในแชต
- ผู้ดูแล LINE OA เพื่อกำหนด LINE Login/LIFF, callback และการอนุญาตใช้ข้อมูล
- บัญชีร้านค้า Shopee/TikTok และแนวทางให้สิทธิ์เชื่อมต่อที่แพลตฟอร์มอนุมัติ รวมถึงรหัสสินค้าและขั้นตอนจับคู่
- แหล่งออเดอร์/สต็อกหลัก กติกาการสะสมแต้มและแลกของรางวัล ช่องทางที่เข้าร่วม การคืนสินค้า/แต้ม และวิธีตรวจสอบการซื้อหน้าร้าน
- รายละเอียดโปรโมชั่นที่มีผลจริงในแต่ละเดือน และนโยบาย PDPA/ข้อความยินยอมที่บริษัทอนุมัติ
